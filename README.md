# Елена · Клининг | Демо-сайт

Профессиональный одностраничный лендинг для частного клининга в Москве.

## 🎯 О проекте

Это демонстрационный маркетинговый сайт, созданный для представления услуг уборки квартир на Авито (объявление 4239905678). Сайт создан с целью показать клининговые услуги в более профессиональном виде.

## 🏠 Услуги

- Поддерживающая уборка (от 3 000 ₽)
- Генеральная уборка
- Уборка после ремонта
- Работа в районе Профсоюзная / Академическая
- Выезд по всей Москве

## 🛠 Технологии

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React 19**

## 🚀 Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшена

```bash
npm run build
```

### Запуск продакшен-версии

```bash
npm start
```

## 📦 Деплой на Vercel

Проект полностью готов к деплою на Vercel:

1. Подключите репозиторий к Vercel
2. Vercel автоматически определит Next.js и выполнит сборку
3. Сайт будет доступен по предоставленному URL

Или используйте Vercel CLI:

```bash
npx vercel
```
